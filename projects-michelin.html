Michelin Marketing Analytics

LLM extraction pipeline and principal component analysis

Team of 5Xiuhan Chen, Sarah Cho, Zixin Meng, Yueqi Lyu, Verena Amanda

  • AI/LLM Automation
  • Data Analysis
  • Prompt Engineering
assets/michelin/cover.png

The question: across 18,422 Michelin-listed restaurants in 19 countries, what actually separates a 3-star restaurant from a 0-star one — food, or something else?

I designed the taxonomy and extraction pipeline this analysis sits on. Michelin inspector write-ups are unstructured prose, so I built a strict, evidence-only prompt for GPT-4.1-mini — the model could only flag an attribute as "mentioned" if it could point to literal wording, with explicit invalid-inference examples built into the prompt to stop it reading things into the text that weren't there. I'd originally tried sentiment scoring on a pilot sample, found Michelin inspectors basically never write anything negative regardless of star tier, and pivoted the entire approach to binary attribute-mention detection instead — a real methodology correction, not a first-try success.

That produced structured data across 8 attribute categories for all 18,422 restaurants, which I ran through a PCA. A single component — "Practical Value to Culinary Mastery" — explained roughly 68.5% of the variance between restaurants: the thing that actually separates Michelin tiers is food and service execution, not ambience, not price. A second component (~25.5%) let us build a perceptual map showing the story arc from 0-star (competing on price and accessibility) to 3-star ("ritualized perfection" — precision, environment, timing, and emotion, all at once).
